# Upgrade minimal-calcit to Calcit 0.13.77

- UTC: 2026-09-04T18:17:02Z
- Issue: calcit-lang/calcit#712

## English

- Align the declared Calcit toolchain and JavaScript runtime package with the published 0.13.77 release.
- Direct users to the 0.13.77 prebuilt binary because that release's crates.io package is not installable on stable Rust.
- Keep the repository test on `ubuntu-latest`, pin every third-party action to an immutable commit, and disable persisted checkout credentials.
- Verify the exact Calcit, Node 24, and Yarn 4.12.0 toolchain before running immutable dependency installation, strict Caps checks, canonical Snapshot formatting, check-only analysis, native runtime, JavaScript generation, and Node runtime smoke tests.

## 中文

- 将声明的 Calcit 工具链与 JavaScript runtime 包同步到已发布的 0.13.77。
- 引导用户使用 0.13.77 预构建二进制，因为该版本的 crates.io 包无法在 stable Rust 上安装。
- 保持仓库测试运行于 `ubuntu-latest`，将所有第三方 Action 固定到不可变提交，并禁用 checkout 凭据持久化。
- 在不可变依赖安装、Caps 严格检查、Snapshot 规范格式、check-only 分析、native runtime、JavaScript 生成和 Node runtime smoke 之前，精确核验 Calcit、Node 24 与 Yarn 4.12.0。
